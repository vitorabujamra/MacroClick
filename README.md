# MacroClick

Auto clicker para Android com gravação de toques, alvos múltiplos e macros salvos.

## Baixar
Última versão: **[MacroClick.apk](../../releases/download/latest/MacroClick.apk)** (gerado pelo GitHub Actions a cada push).

## Recursos
- **Gravar** toques, toques longos e deslizes enquanto usa o celular normalmente
- **Alvos manuais** (＋): círculos numerados arrastáveis — 1 alvo = clique simples, vários = sequência
- **Cliques múltiplos**: cada passo pode repetir N vezes com intervalo próprio
- **Repetições** do macro: 1x, 3x, 5x, 10x, 50x, 100x ou infinito
- **Salvar, editar, duplicar, excluir** macros; exportar/importar em JSON
- Editor de atraso, duração, repetição e ordem de cada passo

## Instalação
1. Instale o APK (permita "fontes desconhecidas").
2. Abra o MacroClick → **Ativar serviço** → Acessibilidade → MacroClick → ativar.
   - Android 13+: se aparecer "configuração restrita", vá em Configurações → Apps → MacroClick → ⋮ → *Permitir configurações restritas*.
   - Xiaomi/MIUI/HyperOS: ative **Início automático** e coloque a bateria em **Sem restrições** para o serviço não ser encerrado.
3. O painel flutuante aparece na lateral da tela.

## Painel
| Botão | Função |
|---|---|
| ⠿ | arrastar o painel |
| ▶ / ■ | executar / parar |
| ● / ■ | gravar / parar gravação |
| ＋ | adicionar alvo de toque |
| 1x | alternar repetições (até ∞) |
| 👁 | mostrar/ocultar alvos |
| 💾 | salvar macro |
| 🗑 | segurar para limpar |
| ☰ | abrir o app |
| ✕ | fechar painel |
